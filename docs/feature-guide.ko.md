# Launchpad 기능 개요

이 가이드는 잠재적 구매자를 위한 Launchpad 스타터 키트의 간결한 개요입니다. 이 키트에 포함된 내용, 외부 서비스나 설정이 필요한 부분, 그리고 키트가 자동으로 제공하지 않는 사항을 요약합니다. 구매한 프로젝트의 전체 기능 가이드와 소스 코드가 여전히 공식적인 구현 참고 자료입니다.

## Launchpad에 포함된 내용

Launchpad는 하나의 공유 코드베이스 위에 구축된 모듈형 SaaS 애플리케이션입니다. 선택적 모듈은 청구, AI 채팅, 조직, 게시, 지원, 커뮤니티, 알림, 이메일 마케팅, 분석, 추천, 광고, SEO, 통합, 개인 파일 저장을 포함합니다. 설정 마법사를 통해 유지할 선택적 모듈과 배포 대상이 무엇인지 선택할 수 있습니다. 핵심 계정, 보안, 설정 및 공유 데이터베이스 구성 요소는 그대로 유지됩니다.

Git 체크아웃에서 설정은 sparse-checkout을 사용하여 제외된 추적 파일이 Git 히스토리에 남아 있도록 합니다. 구매한 ZIP 파일의 경우, 제외된 모듈 파일은 추출된 프로젝트에서 제거됩니다. ZIP에는 저장소 메타데이터가 포함되어 있지 않으므로 Git 히스토리에서 복원할 수 없습니다. 이는 일회성 설정이며, 자리에서 모듈을 전환하는 도구가 아닙니다. 나중에 제외된 소스를 복구하고 싶을 수 있다면 설정 전에 추출된 ZIP을 백업하십시오.

마법사는 선택된 모듈과 배포 설정을 `launchpad.config.json`에, 프로바이더 시크릿을 Git에서 무시되는 `.env` 파일에 기록합니다. **연결 테스트**를 명시적으로 선택할 때 선택된 프로바이더 자격 증명을 확인할 수 있습니다. 프로바이더 계정을 생성하거나, 인프라를 배포하거나, 외부 대시보드를 구성하지는 않습니다. 해당 서비스를 스스로 완료하고 유지 관리해야 합니다.

플러그인 영역은 번들된 구성 요소의 허용 목록을 노출합니다. 이는 임의의 패키지 마켓플레이스가 아니며, 업로드된 플러그인 코드를 다운로드하거나 실행하지 않습니다. 선택적 이벤트 릴레이 서비스는 현재 지원되는 계정 프로필 업데이트 이벤트에 대해 별도로 배포할 수 있습니다. 이는 일반적인 서비스 레지스트리, 메시지 버스 또는 소비자별 확인 시스템이 아닙니다.

## 계정 및 보안

인증은 이메일 로그인과 선택적인 Google 및 GitHub 로그인을 지원합니다. 개발 환경에서는 이메일 프로바이더가 구성되지 않은 경우 Mailpit가 로그인 메일을 수신할 수 있습니다. 배포된 환경에서는 이메일 로그인과 트랜잭션 메일을 위해 이메일 프로바이더가 필요합니다. 관리자 페이지와 API는 서버에서 역할을 강제합니다.

선택적 TOTP 다중 인증은 호환되는 인증기 앱과 함께 작동하며 일회용 복구 코드를 포함합니다. 보안 설정에는 세션 관리와 감사 활동이 포함됩니다. 이 키트는 비밀번호 기반 로그인이나 비밀번호 복구 플로우를 포함하지 않습니다.

계정 온보딩 체크리스트는 프로필 설정, 계정 보안, 대시보드를 다루며, 선택 사항이며 다시 방문할 수 있습니다.

## 청구 및 유료 액세스

청구 모듈은 구성된 구독과 일회성 Lifetime 구매에 대해 Stripe Checkout을 지원하며, Stripe Customer Portal도 포함합니다. 필수 제품, 자격 증명, 스토어 계정, 네이티브 클라이언트 통합이 구성된 경우 선택적 Apple App Store 및 Google Play 구매 검증이 또 다른 청구 소스를 제공할 수 있습니다. 설정이 제공될 때까지 스토어 라우트는 사용할 수 없으며, Stripe는 독립적으로 계속 작동할 수 있습니다.

이 키트는 검증된 결제 및 구독 이벤트를 처리하고, 결제 이력을 기록하며, 환불과 분쟁을 처리합니다. 청구가 활성화되었다는 이유만으로 제품의 모든 기능을 자동으로 보호하지 **않습니다**. `paymentBlocked`는 청구 신호이지 보편적인 페이월이 아닙니다. 각 유료 기능은 서버에서 액세스를 강제해야 하며, 브라우저에서 버튼을 숨기는 것만으로는 충분하지 않습니다. 어떤 기능이 유료인지, 제한된 고객이 여전히 무엇을 할 수 있는지 결정하고, 그런 규칙을 구현하고 테스트하십시오. 이 키트는 Stripe 외부에서 이루어진 결제를 검증하기 위한 완성된 관리자 워크플로우도 포함하지 않습니다.

청구 이메일은 구성된 이메일 프로바이더를 사용하지만, 청구가 작동하려면 이메일이 필수적이지는 않습니다. 불확실한 네트워크 응답 후 이메일 전송이 지연되거나 실패하거나 중복될 수 있으며, 이는 정확히 한 번만 전달하는 시스템이 아닙니다.

## 이메일, 대기 목록, 마케팅

공유 이메일 전송은 Resend, SendGrid, SMTP를 지원합니다. 인증, 청구 통지, 알림, 뉴스레터, 마케팅 메시지에 사용됩니다. 발신자 ID와 프로바이더 자격 증명을 구성해야 합니다. 설정 마법사의 SMTP 체크는 메시지를 보내지 않고 인증만 수행합니다.

현지화된 얼리 액세스 대기 목록은 명시적인 동의를 요구합니다. 그 상태는 수동으로 관리됩니다: 초대하거나 누군가를 가입한 것으로 표시하는 것은 계정을 생성하거나, 초대를 보내거나, 액세스를 부여하지 않습니다. 대기 목록 동의는 뉴스레터 구독과 별개입니다.

뉴스레터는 동의 기반 가입, 구독 취소 링크, 관리자가 생성한 평문 캠페인을 지원합니다. 마케팅 자동화는 새로운 뉴스레터 구독자를 위한 짧은 이메일 시퀀스를 지원합니다. 이 도구는 시각적 이메일 편집기, 대상 세분화 시스템, 또는 컴플라이언스/법률 서비스가 아닙니다. 대기 목록 항목을 자동으로 등록하거나 푸시 알림과 웹훅을 통해 메시지를 보내지 않습니다. 예약된 캠페인과 자동화는 외부 스케줄러와 구성된 이메일 프로바이더가 모두 필요합니다.

## AI 어시스턴트 및 조직

선택적 대시보드 어시스턴트는 구성된 OpenAI 호환 텍스트 API에 연결합니다. 대화는 애플리케이션 데이터베이스에 저장되고, 계정 요청 한도를 강제하며, 개인 및 조직 대화를 지원합니다. 모델을 포함하지 않고, 도구를 실행하거나, 자율적인 행동을 취하지 않습니다. 프롬프트와 응답은 구성된 프로바이더로 전송되고 애플리케이션에 의해 저장됩니다. 프로바이더의 프라이버시 및 보존 설정을 구성하고, 이 처리를 사용자에게 공개하십시오.

조직은 공유 워크스페이스, 멤버 역할, 초대를 제공합니다. 권한은 조직 멤버십에 대해 확인되지만, 이는 고객별로 별도의 데이터베이스나 스키마가 아닌 공유 데이터베이스 테넌시입니다. 청구, 계정 설정, 지원, 알림, 분석, 뉴스레터, 글로벌 게시 콘텐츠는 자동으로 조직 범위로 제한되지 않습니다.

## 게시, 지원, 커뮤니티

별도의 모듈이 현지화된 Markdown 블로그, 릴리스 업데이트 피드, CMS 페이지를 제공합니다. 관리자는 초안과 게시된 콘텐츠를 관리합니다. 공개 페이지에는 현지화된 메타데이터와 사이트맵 지원이 포함됩니다. 게시 도구는 예약된 게시, 자동 번역, 이미지 업로드, 댓글 조정 시스템을 포함하지 않습니다.

지원 모듈은 고객 티켓과 관리자 답변을 제공합니다. 커뮤니티 모듈은 토론 포럼을 제공합니다. 큐레이션된 디렉토리는 관리자가 공개 항목을 관리할 수 있게 합니다. 이들은 호스팅된 헬프 데스크나 완전한 소셜 네트워크와의 통합이 아니라 시작 기능입니다: 첨부 파일, 할당/SLA 자동화, 포럼 반응, 채택된 답변, 공개 사용자 프로필은 포함되지 않습니다.

## 알림 및 고객 데이터

대시보드에는 영구적인 알림 수신함과 선택적 이메일, Web Push, 서명된 웹훅 전달 채널이 있습니다. 푸시 알림은 VAPID 키와 브라우저 구독이 필요하며, 웹훅 소비자는 서명을 검증하고 이벤트를 중복 제거해야 합니다. 알림, 마케팅, 저장소 정리용 자동 재시도는 외부에서 예약된 작업이 필요합니다.

계정 설정은 지원되는 계정 데이터의 JSON 내보내기와 청구 관리로 가는 별도 링크를 제공합니다. 내보내기는 자격 증명, 세션, 서명 시크릿, 기타 민감한 토큰을 제외합니다. 이는 스트림된 다운로드이지, 전체 데이터베이스 백업이나 백그라운드 아카이브 서비스가 아닙니다.

## 분석, 현지화, 사용자 정의

대시보드에는 계정 및 청구 뷰가 포함됩니다. 선택적 제품 분석은 동의 게이트된 이벤트를 수집하고 관리자 보고서를 제공하며, 이는 제3자 분석 플랫폼의 대체재가 아닙니다. 귀속, 마케팅 추적, 추천 쿠키는 배포 환경에서 동의 의무가 있을 수 있습니다. Launchpad에는 동의 관리 플랫폼이 포함되지 않습니다.

인터페이스는 18개 로케일을 지원합니다: 영어, 아랍어, 벵골어, 독일어, 스페인어, 프랑스어, 힌디어, 인도네시아어, 이탈리아어, 일본어, 한국어, 네덜란드어, 폴란드어, 포르투갈어, 러시아어, 터키어, 베트남어, 중국어. 영어는 폴백 카탈로그이자 설정 마법사의 폴백 언어입니다. 출시 전에 대상 독자를 위한 번역과 법적 문구를 검토하십시오.

제품 빌더는 애플리케이션 섹션, 내비게이션, 현지화된 카피, 브랜드 설정의 허용 목록을 편집합니다. 임의의 코드를 생성하거나, 애플리케이션 라우트를 생성하거나, 비즈니스 로직을 변경하지 않습니다. 테마, 모션, 기타 개인 인터페이스 선호도는 브라우저에 저장되며, 기기 간에 동기화되지 않습니다.

## 저장소, 추천, 광고, SEO

선택적 개인 파일 저장은 S3 호환 객체 저장을 사용합니다. 애플리케이션은 파일 유형과 크기를 검증하고, 짧은 수명의 업로드/다운로드 URL을 사용하며, 파일 소유권을 확인합니다. 개인 버킷과 필수 자격 증명을 구성하십시오. 이 모듈은 파일을 악성ware로 스캔하지 않으며, 계정 삭제 시 원격 객체를 자동으로 제거하지 않습니다.

추천 모듈은 파트너 링크와 Stripe에서 파생된 수수료를 추적합니다. 지급은 Launchpad 외부에서 수행됩니다. App Store 또는 Google Play 구매에 대한 수수료를 계산하지 않습니다. 추천 귀속은 30일 쿠키를 사용하며, Launchpad에는 내장된 동의 관리자가 없으므로 적용 가능한 동의 요구 사항을 평가하고 구현하십시오.

광고 도구는 캠페인 및 계정 정보를 정리하고 CSV에서 보고서를 가져옵니다. 광고 네트워크에 연결하여 라이브 캠페인을 생성하거나 관리하지 않습니다. SEO 기능은 현지화된 메타데이터, 사이트맵, robots 규칙, 구조화된 데이터, 애플리케이션 데이터베이스 감사를 제공하며, 이는 웹 크롤러, 랭킹 트래커, 키워드 연구 도구, 리다이렉트 관리자가 아닙니다.

통합 카탈로그는 예상되는 구성이 존재하는지 보고합니다. 자격 증명이 작동하는지 증명하거나, 프로바이더 계정을 생성하거나, 전달을 보장하지는 않습니다.

## 배포 및 운영 책임

배포에는 PostgreSQL과 적절한 환경 변수, 데이터베이스 연결 및 `AUTH_SECRET`가 필요합니다. 활성화하는 기능에 대해서만 이메일, Stripe, 스토어 청구, 객체 저장소, AI, 푸시, 예약된 작업을 구성하십시오. 프로덕션 마이그레이션은 문서화된 배포 프로세스를 사용하여 적용해야 하며, 미리보기 환경은 격리된 데이터베이스를 유지하십시오.

애플리케이션에는 서버 측 검증, 역할 체크, 보안 제어, 감사 로깅이 포함되지만, 완전한 보안 운영 프로그램은 아닙니다. WAF, 악성ware 스캔, 외부 보안 모니터링, 엄격한 Content Security Policy를 제공하지 않습니다. 신뢰할 수 있는 인그레스와 호스팅 보호를 구성하고, 위협 모델을 검토하며, 출시 전에 배포된 애플리케이션을 테스트하십시오.
