# Launchpad 功能概览

本指南为潜在买家提供了 Launchpad 启动套件的简明概述。它总结了套件包含的内容、哪些部分需要外部服务或配置，以及套件不会自动提供的功能。所购项目的完整功能指南和源代码仍是权威的实作参考。

## Launchpad 包含的内容

Launchpad 是一个基于单一共享代码库构建的模块化 SaaS 应用程序。其可选模块涵盖计费、AI 聊天、组织、发布、支持、社区、通知、电子邮件营销、分析、推荐、广告、SEO、集成以及私有文件存储。设置向导允许您选择要保留哪些可选模块以及部署目标。核心账户、安全、设置和共享数据库组件将保持不变。

在 Git 检出中，设置使用 sparse-checkout，因此被排除的受跟踪文件仍保留在 Git 历史中。在购买的 ZIP 文件中，被排除的模块文件会从解压后的项目中移除；由于 ZIP 文件不包含仓库元数据，因此无法从 Git 历史中恢复它们。这是一次性设置，而非就地模块切换工具。如果您可能希望稍后恢复被排除的源代码，请在配置之前备份解压后的 ZIP 文件。

向导会将所选模块和部署偏好写入 `launchpad.config.json`，并将提供商密钥写入被 Git 忽略的 `.env` 文件。当您明确选择 **测试连接** 时，它可以检查所选提供商的凭据。它不会创建提供商账户、部署基础设施或配置外部仪表板。您仍需自行完成并维护这些服务。

插件区域暴露了一组允许列表中的捆绑组件；它不是一个任意的包市场，也不会下载或执行上传的插件代码。可选的事件中继服务可以单独部署，用于当前支持的账户资料更新事件。它不是一个通用的服务注册表、消息总线或按消费者确认的系统。

## 账户与安全

身份验证支持电子邮件登录以及可选的 Google 和 GitHub 登录。在开发环境中，如果未配置电子邮件提供商，Mailpit 可以接收登录邮件。部署环境需要电子邮件提供商以支持电子邮件登录和事务性邮件。管理页面和 API 在服务器端强制实施角色权限。

可选的 TOTP 多因素身份验证与兼容的身份验证器应用配合使用，并包含一次性恢复代码。安全设置包括会话管理和审计活动。该套件不包含基于密码的登录或密码恢复流程。

账户入门检查清单涵盖个人资料设置、账户安全和仪表板；它是可选的，并且可以重新访问。

## 计费与付费访问

计费模块支持针对已配置订阅和一次性终身购买的 Stripe Checkout，以及 Stripe 客户门户。可选的 Apple App Store 和 Google Play 购买验证可以在配置了所需产品、凭据、商店账户和原生客户端集成后，提供另一个计费来源。在提供其设置之前，商店路由不可用；Stripe 可以继续独立运行。

该套件处理经过验证的支付和订阅事件，记录支付历史，并处理退款和争议。它 **不会** 仅仅因为启用了计费就自动保护您产品中的每个功能。`paymentBlocked` 是一个计费信号，而非通用的付费墙。每个付费功能都必须在服务器端强制实施访问控制；仅在浏览器中隐藏按钮是不够的。决定哪些功能是付费的，以及受限客户仍可以做什么，然后实施并测试这些规则。该套件也不包含用于验证 Stripe 之外支付的现成管理员工作流程。

计费电子邮件使用已配置的电子邮件提供商，但计费功能不依赖电子邮件即可运行。电子邮件投递可能会延迟、失败或在网络响应不确定后重复；它不是一个恰好一次投递的系统。

## 电子邮件、等待列表与营销

共享电子邮件传输支持 Resend、SendGrid 和 SMTP。它用于身份验证、计费通知、通知、通讯和营销消息。必须配置发件人身份和提供商凭据。设置向导的 SMTP 检查在不发送消息的情况下进行身份验证。

本地化的早期访问等待列表需要明确同意。其状态是手动管理的：邀请某人或将其标记为已加入不会创建账户、发送邀请或授予访问权限。等待列表同意与通讯订阅是分开的。

通讯支持基于同意的注册、取消订阅链接以及管理员创建的纯文本活动。营销自动化支持针对新通讯订阅者的短电子邮件序列。这些工具不是可视化电子邮件编辑器、受众细分系统或合规/法律服务。它们不会自动将等待列表条目注册或通过网络推送通知和 Webhook 发送消息。计划好的活动和自动化还需要外部调度器以及已配置的电子邮件提供商。

## AI 助手与组织

可选的仪表板助手连接到已配置的 OpenAI 兼容文本 API。它在应用程序数据库中存储对话，强制实施账户请求限制，并支持个人和组织对话。它不包含模型、不执行工具，也不采取自主行动。提示和响应会发送到已配置的提供商并由应用程序存储；请配置提供商的隐私和保留设置，并向用户披露此处理过程。

组织提供共享工作区、成员角色和邀请。授权是根据组织成员身份进行检查的，但这是共享数据库租户模式，而不是为每个客户提供单独的数据库或模式。计费、账户设置、支持、通知、分析、通讯和全局发布内容不会自动按组织范围划分。

## 发布、支持与社区

单独的模块提供本地化的 Markdown 博客、发布更新源和 CMS 页面。管理员管理草稿和已发布内容。公共页面包括本地化元数据和站点地图支持。发布工具不包含计划发布、自动翻译、图像上传或评论审核系统。

支持模块提供客户工单和管理员回复。社区模块提供讨论论坛。精选目录允许管理员管理公共条目。这些是入门功能，而不是与托管帮助台或完整社交网络的集成：附件、分配/SLA 自动化、论坛反应、已接受答案和公共用户资料均不包含在内。

## 通知与客户数据

仪表板具有持久通知收件箱以及可选的电子邮件、Web Push 和签名 Webhook 投递渠道。推送通知需要 VAPID 密钥和浏览器订阅；Webhook 消费者必须验证签名并去重事件。通知、营销和存储清理的自动重试需要外部调度的任务。

账户设置提供受支持账户数据的 JSON 导出以及指向计费管理的单独链接。导出排除了凭据、会话、签名密钥和其他敏感令牌。它是一个流式下载，而不是完整的数据库备份或后台归档服务。

## 分析、本地化与自定义

仪表板包括账户和计费视图。可选的产品分析收集受同意控制的事件并提供管理报告；它们不是第三方分析平台的替代品。归因、营销跟踪和推荐 Cookie 在您的部署中可能具有同意义务。Launchpad 不包含同意管理平台。

界面支持 18 种语言环境：英语、阿拉伯语、孟加拉语、德语、西班牙语、法语、印地语、印度尼西亚语、意大利语、日语、韩语、荷兰语、波兰语、葡萄牙语、俄语、土耳其语、越南语和中文。英语是回退目录，也是设置向导的回退语言。在发布前，请针对您的受众审查翻译和法律文本。

产品构建器编辑一组允许列表中的应用部分、导航、本地化文案和品牌设置。它不生成任意代码、不创建应用程序路由，也不更改业务逻辑。主题、动效和其他个人界面偏好存储在浏览器中，而不是跨设备同步。

## 存储、推荐、广告与 SEO

可选的私有文件存储使用 S3 兼容的对象存储。应用程序验证文件类型和大小，使用短生命周期的上传/下载 URL，并检查文件所有权。请配置私有存储桶和所需的凭据。该模块不扫描文件中的恶意软件，且账户删除不会自动移除远程对象。

推荐模块跟踪合作伙伴链接和源自 Stripe 的佣金。付款在 Launchpad 之外执行。它不为 App Store 或 Google Play 购买计算佣金。推荐归因使用 30 天 Cookie；Launchpad 没有内置的同意管理器，因此请评估并实施适用的同意要求。

广告工具整理活动和账户信息，并从 CSV 导入报告。它们不连接到广告网络以创建或管理实时活动。SEO 功能提供本地化元数据、站点地图、robots 规则、结构化数据和应用程序数据库审计；它们不是网络爬虫、排名跟踪器、关键词研究工具或重定向管理器。

集成目录报告预期的配置是否存在。它不证明凭据有效、不创建提供商账户，也不保证投递。

## 部署与运营责任

部署需要 PostgreSQL 和适当的环境变量，包括数据库连接和 `AUTH_SECRET`。仅为您启用的功能配置电子邮件、Stripe、商店计费、对象存储、AI、推送和计划任务。生产迁移必须使用文档中描述的部署流程应用；请保持预览环境使用隔离的数据库。

应用程序包含服务器端验证、角色检查、安全控制和审计日志，但它不是一个完整的安全运营计划。它不提供 WAF、恶意软件扫描、外部安全监控或严格的 Content Security Policy。请配置受信任的入口和托管保护，审查威胁模型，并在发布前测试已部署的应用程序。

有关详细配置、数据所有权、限制、迁移和运营程序，请参阅随项目提供的完整功能指南。
